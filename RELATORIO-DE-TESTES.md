# Versão 19 — correção de foco e entrega completa

Corrigido o atributo tabindex do editor em todas as páginas. A rotina de foco também define o atributo antes de focar, garantindo funcionamento no navegador real, inclusive se uma página antiga omitir o atributo.
Mantidas as dependências locais de IA, OCR e fontes. Guia PUBLICAR-NO-GITHUB.md explica como enviar o conjunto completo pelo GitHub Desktop ou navegador.
Nesta rodada: regressões específicas de foco, conferência de referências de HTML, dependências dos workers/modelos, idiomas do OCR, manifesto e extração byte a byte do ZIP.
O histórico de 78 testes da versão 18 não foi executado novamente nesta rodada; o ambiente anterior de testes não está disponível. As alterações são restritas a foco, marcação HTML, versões de cache e documentação. A versão 19 ainda precisa de conferência no GitHub após upload.
